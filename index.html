From a crumpled receipt to
the day's margin on WhatsApp.
A WhatsApp assistant that lets restaurant staff log purchases by voice, text or photo — and answers the hardest question in any small business: how much is left after costs.
n8n WhatsApp API AI Agents Python Google Sheets Fudo API
● Delivered · Sep 2026
First FSConsultory client
THE PROBLEM

A small restaurant knows exactly how much it sold — the POS tells it that. What it almost never knows on time is how much it spent, because costs live in crumpled receipts in the cook's pocket, in loose messages, and in purchases nobody logged.

Logging costs is administrative work nobody wants to do in the middle of a service. The bet: if logging a purchase costs the same as sending a WhatsApp voice note, it will get done.

HOW IT WAS BUILT
⚙️
Numbers never go through a language model. The model understands the message; the code does the math.
🔍
The code checks the model. When the assistant reads a receipt, it compares the sum of line items against the printed total and flags mismatches.
🤫
When it doesn't know, it stays silent. Price alerts only fire when the system is certain which product and package it's looking at.
📊
The system tells you what it isn't counting. Every margin response ends by stating how many costs were included.
8 SILENT DEFECTS CAUGHT BEFORE DELIVERY
#1
A tax counted twice. The system added VAT already included in line prices, inflating costs by 15% with a total that looked perfectly credible.
#2
A correction that raised the price instead of lowering it. Two prompts interpreted the same phrase in opposite directions.
#3
Invented comparisons. "Aceite" matched four products at very different prices — alerting about a product the restaurant never bought.
#4
Lost traceability. Every voice-logged purchase was saved as text with no audio transcript — the record needed when someone disputes what was said.
#5
A query that never worked. The API always replied no expenses — whether there were any or not.
→
A zero is not data — it's a hypothesis. An empty response deserves the same suspicion as a strange one.
"The system responded something reasonable while doing something wrong." That is the signature of a silent defect.
— FSConsultory · Engineering criterion
